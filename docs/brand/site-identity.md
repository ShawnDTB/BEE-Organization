# BEE Organization — Site Identity System

This document defines the development identity currently used across the BEE Organization platform. It is intentionally strong enough to create a coherent customer experience while the final public-facing name and production logo remain subject to approval.

## Brand position

**Engineered production studio × modern streetwear × boutique technology workshop.**

BEE should feel like a place where garments, artwork, equipment, and systems are built deliberately. The identity should bridge apparel production and technical craft without looking like generic industrial software or a mascot-led print shop.

## Visual principles

- Engineered, modular, and fabrication-aware
- Dark and premium without becoming sterile
- Apparel/editorial presentation on storefront pages
- Technical interface language reserved for Studio, proofing, projects, and account tools
- Warm material contrast rather than neon color
- Small registration/alignment details instead of decorative clutter
- Sharp geometry with occasional cut-corner controls
- Photography and real finished work should eventually carry most of the storefront personality

## Core palette

| Token | Value | Use |
| --- | --- | --- |
| Carbon | `#090B0C` | Main page background |
| Graphite | `#101315` | Primary surfaces |
| Graphite 2 | `#171B1D` | Raised surfaces |
| Bone | `#EEE7DA` | Primary text / light material tone |
| Steel | `#747D81` | Structural lines and secondary details |
| Steel Light | `#A5ADAF` | Secondary text and technical labels |
| Copper | `#B97732` | Primary production accent |
| Copper Bright | `#D59A52` | Hover, active, and editorial accent |

Copper is intentionally restrained. It should identify actions, active states, registration details, and important production information rather than fill large areas of the interface.

## Typography

- **Space Grotesk** — display headings, product names, project titles, key metrics
- **Inter** — navigation, body copy, controls, forms, production metadata

Headings should feel editorial and streetwear-aware. Small labels may use technical tracking/uppercase treatment, but readable UI copy should not be reduced to tiny decorative text.

## Mark direction

The current development mark uses a modular geometric **B** assembled from fabrication-like blocks inside a technical frame. Small copper registration points provide the subtle BEE reference through repetition/structure rather than depicting an insect.

The mark is a development identity and should remain easy to replace if the final public name changes.

## Do not use

The following directions were explicitly rejected:

- Hornet or bee mascots
- Wings
- Stingers
- Honey drips
- Hive illustrations
- Honeycomb used as a dominant motif
- Hazard stripes
- Insect-heavy iconography
- Generic black/yellow sports-team branding
- Neon gamer aesthetics as the primary identity

## Interface behavior

### Public storefront

Use larger imagery, real apparel, collection storytelling, and simple purchasing paths. The technical identity should frame the merchandise rather than overpower it.

### BEE Studio

This is where the technical/workshop identity can become more explicit: grids, registration zones, placement controls, garment surfaces, production notes, and precise active states.

### Customer workspace

Prioritize project status, proofs, saved designs, reorders, and next actions. Copper identifies current or actionable states; graphite/steel structures the interface.

### Service pages

Keep sections compact and practical. Use production photography/details as they become available rather than filling space with oversized brand statements.

## Brand integrity

Do not fabricate customer work, testimonials, sales volume, production capacity, pricing, turnaround guarantees, creator partnerships, or collection history. The visual identity should look established while the content remains truthful about the business's current stage.
