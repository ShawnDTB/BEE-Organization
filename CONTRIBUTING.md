# Contributing

## Branches

- `main`: production-ready work
- `staging`: integrated client-review work
- `feature/*`: scoped feature development

## Commit style

Use concise imperative commits, for example:

- `Add identity board foundation`
- `Build quote intake shell`
- `Refine mobile navigation`

## Pull requests

Every pull request should explain what changed, why it changed, customer impact, validation performed,
and any content, legal, pricing, or production decisions still required.
