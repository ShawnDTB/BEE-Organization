# Customer Clarity Pass

This pass is intentionally selective. The goal is not to make every page shorter. It is to remove repetition only where a customer gains nothing from the extra content.

## Keep depth where the customer is doing work

Do not aggressively condense:

- BEE Studio controls and garment configuration
- Project Bag editing
- Project Review information capture
- Customer workspace timelines, proofs, quotes, payments, saved designs, and reorders
- Product detail information once finished merchandise is available
- Group Collector roster and participation tools

These areas benefit from context because the customer is making a decision, entering information, or managing an active project.

## Condense where the site is explaining itself

Prioritize reduction on:

- Homepage repeated explanations of the same three customer paths
- Pre-launch Shop copy explaining why products are not available
- Bulk-order sections that repeat garment / quantity / artwork / timing information
- Placeholder/sample messaging that exists only because real work is not available yet
- Repeated process explanations already understood elsewhere

## Customer-first test

A section should remain if it helps answer one of these questions:

1. What can I buy or make?
2. Is this right for my project?
3. What does it look like?
4. What do I need to provide?
5. What happens next?
6. What needs my attention?

If it does not materially help with one of those questions, earn trust with real evidence, or enable an action, it should usually be removed.

## Background direction

The site-wide grid is retired. Grids remain appropriate inside BEE Studio where they function as placement and production tools.

The public site background instead uses an abstract production-pattern field inspired by:

- garment pattern drafting curves
- seam and stitch paths
- registration / alignment marks
- cutting-table notation
- subtle copper production checkpoints

The motif should stay quiet enough that apparel imagery and content remain dominant. It is a brand-supporting production texture, not decorative wallpaper.
